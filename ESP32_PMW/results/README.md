# Experimental results

Every file here is an **output**. Each is regenerated by the script named below,
so nothing here is a source and nothing here needs to be preserved by hand.

Only the two PNG sets are tracked. `pose_validation/` and `elp/` are gitignored
(neither exists right now; both are rebuilt from the pipeline on demand). The
remaining entries below are untracked but *not* ignored — they show up in
`git status`, so add them deliberately or leave them alone.

| directory | generated by | from |
|---|---|---|
| `single_vs_multi_coil/` | `ai/plots/plot_coil_current_profiles.py` | `data/2026-07-04a_coupling-matrix/coupling_pairwise_20260704_143320.csv` |
| `pid_decoupling_tuning/` | `ai/plots/plot_pid_tuning_matrix.py` | `data/2026-07-04e_recalibration-ccw/` (CCW, 3-stage) and `data/2026-07-04b_comp-calibration-cw/` (CW, 2-stage) |
| `flights/` *(untracked)* | `controller/camera/record.py` | the live stereo rig; one dir per session, `<date>_<time>/{A,B}/` |
| `stereo_calibration/` *(untracked)* | `controller/calib/calibrate.py`, `calib/plots.py` | a ChArUco capture run; holds `camera_intrinsics_{A,B}.npz`, `pairs/`, `recording/` |
| `rim_extractor_trials.html` *(untracked)* | the rim-extractor study | referenced from `controller/pose/segment.py` |
| `pose_validation/` *(gitignored, absent)* | `ai/validation/sweep.py`, `resolution_sweep.py`, `limits.py`, `fit_error_model.py` | rendered poses, no hardware |
| `open_loop_sweep/` | `controller/control/open_loop_sweep.py` | nothing, it is a model sweep. See [chapter 4 §14](../controller/control/theory.md) |
| `array_optimisation/` *(empty)* | `controller/control/optimise_array.py` | nothing, it is a model search. See [chapter 4 §15](../controller/control/theory.md) |
| `elp/` *(gitignored, absent)* | `controller/camera/modes.py`, `ai/validation/elp_demo.py` | the live camera, and the real captures in `controller/pose/assets/captures/` |

The calibration products that the pipeline *loads* live next to the code that
loads them, because that is where the loaders default:

- `controller/calib/assets/camera_intrinsics.npz` — `estimator.load_intrinsics()`
- `controller/calib/stereo_rig.json` — `rig.StereoRig.load()`
- `controller/calib/tilt_calibration*.json` — `shape.TiltCalibration.load()`

`stereo_calibration/` above is the *output* of a calibration run (coverage plots,
per-camera intrinsics); the files listed here are the ones the live pipeline
reads back.
